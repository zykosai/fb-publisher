# FB Publisher

Локальный помощник для публикаций в группах Facebook: товары, услуги и контент.

[English](README.md) · [Подробное руководство](WEB-APP.md) · [Вклад в проект](CONTRIBUTING.md)

## Как запустить

1. Установи Python 3.11 или новее.
2. Скачай ZIP проекта и полностью распакуй в отдельную папку.
3. Открой **PC START.cmd**. При первом запуске нужен интернет: установятся зависимости и запасной Chromium. Если установлен Google Chrome, бот использует его.
4. Не закрывай окно запуска. Открой полную ссылку, которую оно напечатает, включая `?key=…`.
5. В разделе **Аккаунты** добавь профиль, войди в Facebook и подтверди вход на панели.
6. Добавь объявления, загрузи и проверь группы, создай план публикаций и запусти нужный аккаунт.

`SETUP.cmd` устанавливает или восстанавливает зависимости. `STOPBOT.cmd` ставит аккаунты на паузу и останавливает их процессы. Не открывай несколько копий панели на одном порту.

## Возможности

- Отдельные входы, товары, группы и очереди; несколько аккаунтов могут работать одновременно.
- Интерфейсы «Товары», «Услуги» и «Контент / ИИ». Последний — оформление интерфейса, а не генератор ИИ.
- Добавление объявлений, импорт ZIP и предпросмотр своих объявлений Marketplace.
- Порядок фотографий, необязательный заголовок, SOLD с отменой и статистика продаж.
- Проверка групп с отменой, выделение мышью, пакеты групп через встроенный интерфейс Facebook, расписание и история.
- 11 языков, мобильная версия и сворачиваемый блок аккаунтов.

## Телефон и удалённый доступ

Запусти **TAILSCALE START.cmd**. Подключай телефон или другой компьютер через свою локальную сеть либо частную VPN-сеть. Открой полную ссылку с доступным адресом компьютера и ключом. Компьютер с ботом должен оставаться включённым. Может потребоваться разрешение брандмауэра. Не открывай порт 8765 всему интернету и не передавай ссылку с ключом посторонним.

## Где твои данные

В папке `data/`: аккаунты, cookies, база, фото, журнал, ключ подключения и резервные копии. Эта папка целиком исключена из Git и чистого архива проекта. Перед обновлением сделай приватную резервную копию; сохрани свои `data/` и `.env`. Не отправляй их в Issues и не отдавай другим пользователям.

Настройки необязательны: при необходимости скопируй `.env.example` в `.env`. В новом чистом экземпляре каждый пользователь входит в свои аккаунты самостоятельно.

## Ограничения

Это независимый неофициальный проект. Автоматизация работает через браузер, поэтому изменения Facebook могут нарушить её работу. Не все группы поддерживают обычные записи и пакетную публикацию; одобрение администратора не гарантируется. При ограничении Facebook бот должен остановиться. Мультиаккаунты и Турбо не защищают от блокировок. Не используй приложение для спама, обхода ограничений и чужого контента без разрешения.

## Разработчикам

Запусти `setup.ps1 -Dev`, затем тесты по инструкции в [README](README.md). Чистый архив создаётся командой `python scripts/build_release.py`, а проверка публичных файлов — `python scripts/check_distribution.py`. Инструкция владельцу по размещению находится в [docs/GITHUB.md](docs/GITHUB.md).
